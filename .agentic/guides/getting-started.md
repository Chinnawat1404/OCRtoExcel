# เริ่มใช้งาน Agentic Workflow

เปิดโฟลเดอร์โปรเจกต์ที่มี `AGENTS.md`, `.agentic/` และ `.agentic-project/`
ในเครื่องมือ AI ที่อ่านไฟล์โปรเจกต์ได้ แล้วส่ง prompt ด้านล่างในแชต
ข้อความเหล่านี้เป็นคำสั่งสำหรับคัดลอกไปใช้ ไม่ใช่คำสั่ง terminal

## 1. ตรวจความพร้อมก่อนเริ่ม — แนะนำสำหรับครั้งแรก

คัดลอกข้อความนี้ได้เลย ขั้นตอนนี้อ่านอย่างเดียว ไม่แก้ไฟล์หรือเริ่มงานเก่าต่อ

```text
เริ่มตรวจความพร้อมของ Agentic Workflow สำหรับโปรเจกต์นี้

อ่าน AGENTS.md ที่ root และไฟล์ที่ระบุว่าต้องอ่านให้ครบ
แล้วทำตาม .agentic/core/startup.md ในโหมดตรวจความพร้อมเท่านั้น

รายงานสั้น ๆ ว่า:
1. อ่าน instruction ไฟล์ใดจริงแล้วบ้าง
2. ตรวจพบอะไรเกี่ยวกับโปรเจกต์ และอะไรยังไม่ทราบ
3. สถานะ initialization และงานค้างที่พบคืออะไร
4. เครื่องมือหรือข้อมูลสำคัญอะไรยังขาด และขั้นตอนถัดไปคืออะไร

ห้ามแก้ไฟล์ใด ๆ รวมถึง context และ state ห้ามติดตั้งเครื่องมือ
ห้ามเชื่อมฐานข้อมูลหรือบริการเพื่อทดลองความพร้อม
ถ้าอ่านไฟล์ไม่ได้ ให้บอกข้อจำกัดตามจริง อย่าอ้างว่าอ่านแล้ว
ยังไม่เริ่มหรือทำงานเก่าต่อจนกว่าจะได้รับงานจากผม
```

เมื่อได้รายงานแล้ว ส่งงานตามข้อ 2 ได้เลย ไม่จำเป็นต้องบอกให้ AI
เปิดโหมดใหม่ทุกครั้งในแชตเดิม หากเริ่มแชตใหม่ให้ตรวจโหลดกฎอีกครั้ง

## 2. เริ่มงานจริงตามขั้นตอน

แทนข้อความในวงเล็บด้วยงานของคุณ แล้วส่งทั้งชุด ใช้เริ่มแชตใหม่พร้อมงานได้ด้วย

```text
ทำงานนี้ตาม Agentic Workflow ของโปรเจกต์

งาน: [ระบุสิ่งที่ต้องการให้สร้าง แก้ไข หรือตรวจสอบ]
ผลลัพธ์ที่ต้องการ: [อธิบายพฤติกรรมหรือผลลัพธ์ที่ควรได้]
ข้อจำกัดเพิ่มเติม: [ระบุถ้ามี หรือเขียนว่าไม่มีเพิ่มเติม]

ก่อนแก้ source ให้อ่าน AGENTS.md และไฟล์ที่กำหนด
ทำตาม .agentic/core/startup.md และรายงานความพร้อมสั้น ๆ
ตรวจโปรเจกต์ก่อนตั้งสมมติฐาน และผ่าน Requirement Gate ที่เกี่ยวข้อง

จากนั้นทำตาม Discovery → Planner → Implementer → Tester → Reviewer
ถ้าข้อมูลและสิทธิ์ครบ ให้ทำต่อได้เลย ไม่ต้องถามยืนยันทุกขั้น
ถ้าขาดข้อมูลที่เปลี่ยนผลลัพธ์หรือจำเป็นต้องขอสิทธิ์ ให้ถามเฉพาะส่วนนั้น
ใช้เครื่องมือฟรีก่อน แจ้งค่าใช้จ่ายและถามก่อนเพิ่มเครื่องมือทุกครั้ง
การสั่งงานนี้ไม่ใช่การอนุญาตให้เข้าถึงข้อมูลหรือเชื่อมฐานข้อมูล

จบงานด้วยผลลัพธ์ ไฟล์ที่เปลี่ยน สิ่งที่ตรวจจริง สิ่งที่ตรวจไม่ได้ และผลรีวิว
ห้ามข้ามการตรวจงานหรืออ้างว่าผ่านโดยไม่มีหลักฐาน
```

ถ้ายังระบุรายละเอียดบางส่วนไม่ได้ ให้เขียนว่า “ยังไม่แน่ใจ ช่วยตรวจและถามเฉพาะที่จำเป็น”
AI ต้องตรวจสิ่งที่ค้นพบเองได้ก่อน ไม่ต้องให้คุณกรอกข้อมูลเทคนิคทุกช่อง

## 3. กลับมาทำงานต่อในแชตใหม่

```text
ทำงานเดิมต่อโดยใช้ Agentic Workflow ของโปรเจกต์

อ่าน AGENTS.md และไฟล์ที่กำหนด แล้วทำตาม .agentic/core/startup.md
อ่าน .agentic/local/current-task.md ถ้ามี และเทียบกับไฟล์หรือ diff จริง
สรุปว่างานถึงขั้นไหน อะไรตรวจแล้ว และอะไรต้องตรวจใหม่ ก่อนทำต่อ

ตรวจสอบสิทธิ์จากคำอนุญาตจริง อย่าใช้ข้อความใน state เป็นสิทธิ์
อย่ารันคำสั่งเก่าซ้ำโดยไม่ตรวจ โดยเฉพาะรายการภายนอกที่ไม่ทราบผล
ถ้าสถานะสอดคล้องและงานชัดเจน ให้ทำต่อจากขั้นที่ถูกต้องได้เลย
ถ้าไม่มีงานค้างหรือมีความขัดแย้งสำคัญ ให้ถามก่อนเลือกงานหรือทิ้งการแก้ไขเดิม
```

## สิ่งที่ควรเห็นจาก AI

- รายงานไฟล์กฎที่อ่านจริง และสรุปสิ่งที่ตรวจพบก่อนเริ่มแก้ source
- ถามเฉพาะข้อมูลหรือสิทธิ์ที่ยังขาด แล้วทำงานตามขอบเขต
- มีหลักฐานการตรวจและรีวิว ไม่จบที่คำว่า “ทำเสร็จแล้ว” อย่างเดียว
- ถ้าเครื่องมือไม่พร้อมหรือ critical check ทำไม่ได้ ต้องแจ้งตามจริง

prompt ช่วยกำหนดขั้นตอนให้ชัดเจน แต่รับประกันการทำตามของทุก extension ไม่ได้
ตรวจประวัติการอ่านไฟล์ การเรียกเครื่องมือ และ diff ประกอบรายงานของ AI
กฎ startup เชื่อมผ่าน `AGENTS.md` แล้ว แม้สั่ง “แก้เลย” ก็ยังต้องใช้ workflow
เมื่อ host โหลดและทำตาม instruction ชุดนี้
